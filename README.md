# Link_shortener_new
Сервис сокращения ссылок - приложение, превращающее длинный URL-адрес в короткую удобную ссылку. При клике на неё происходит автоматическое перенаправление (редирект) на исходный сайт. Это помогает делать ссылки эстетичными, экономить место в текстах и отслеживать статистику переходов.
